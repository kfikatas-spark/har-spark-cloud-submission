# Εγκατάσταση και εκτέλεση των πειραμάτων

Οι παρακάτω εντολές εκτελούνται από τον φάκελο `supporting/`. Συνιστάται χωριστό αντίγραφο εργασίας, ώστε τα νέα αποτελέσματα να παραμένουν ξεχωριστά από εκείνα που συνοδεύουν την αναφορά.

## 1. Δομή του κώδικα και των αρχείων

| Διαδρομή | Περιεχόμενο |
|---|---|
| `src/har_spark/` | Κώδικας για την ανάγνωση και τον καθαρισμό των μετρήσεων, τον υπολογισμό χαρακτηριστικών, τον διαχωρισμό των δεδομένων ανά άτομο και την εκπαίδευση και αξιολόγηση με MLlib |
| `configs/` | Ρυθμίσεις για τα τέσσερα πειράματα που πραγματοποιήθηκαν και για έναν σύντομο έλεγχο λειτουργίας |
| `tests/` | Δοκιμές του κώδικα με μικρά συνθετικά σύνολα δεδομένων |
| `results/` | Αποτελέσματα των τεσσάρων τοπικών πειραμάτων: δείκτες αξιολόγησης, στοιχεία για τους πίνακες σύγχυσης, εκπαιδευμένα μοντέλα και γραφήματα |
| `cloud/` | Πρόγραμμα εκτέλεσης στο Google Cloud, αποτελέσματα του πειράματος στο νέφος και οδηγίες εγκατάστασης και εκτέλεσης |
| `scripts/generate_plots.py` | Δημιουργία γραφημάτων από τα ήδη διαθέσιμα αποτελέσματα |
| `data/` | Περιγραφή του WISDM και τιμή SHA-256 για τον έλεγχο του αρχείου δεδομένων· το πλήρες αρχείο λαμβάνεται χωριστά |

Η εφαρμογή επεξεργάζεται τις μετρήσεις που υπάρχουν στα αρχεία WISDM. Δεν συλλέγει νέα δεδομένα από συσκευές σε πραγματικό χρόνο.

## 2. Εγκατάσταση και έλεγχος λειτουργίας

Στα τοπικά πειράματα χρησιμοποιήθηκαν Python **3.11**, Java **17** και PySpark **3.5.3**. Οι βιβλιοθήκες εγκαθίστανται σε εικονικό περιβάλλον Python, χωρίς αλλαγές στην εγκατάσταση Python του Debian:

```bash
python3.11 -m venv "$HOME/.local/share/venvs/har-submission"
. "$HOME/.local/share/venvs/har-submission/bin/activate"
python -m pip install -e '.[dev,docs]'
python -m pytest -q
python -m har_spark.cli --help
```

Οι απαιτούμενες βιβλιοθήκες δηλώνονται στο `pyproject.toml`. Η εγκατάστασή τους απαιτεί σύνδεση στο διαδίκτυο. Οι δοκιμές χρησιμοποιούν συνθετικά δεδομένα και δεν χρειάζονται το πλήρες WISDM ή λογαριασμό Google Cloud.

## 3. Λήψη και έλεγχος των δεδομένων

Χρησιμοποιείται το **WISDM Smartphone and Smartwatch Activity and Biometrics Dataset** του Gary M. Weiss (2019), από το UCI, DOI [10.24432/C5HK59](https://doi.org/10.24432/C5HK59), με άδεια **CC BY 4.0**. Η αρχική περιγραφή των αρχείων, των αισθητήρων και των δραστηριοτήτων βρίσκεται στο `data/DATASET-README.txt`.

Το συμπιεσμένο αρχείο λαμβάνεται από την παραπάνω σελίδα του UCI και αποθηκεύεται ως `data/raw/wisdm-dataset.zip`. Περιέχει το `WISDM-dataset-description.pdf` και ένα δεύτερο αρχείο `wisdm-dataset.zip`, μέσα στο οποίο βρίσκονται οι μετρήσεις. Η διαθέσιμη τιμή SHA-256 αφορά το **εξωτερικό αρχείο**. Αρχικά ελέγχεται η ακεραιότητά του και έπειτα αποσυμπιέζονται διαδοχικά τα δύο αρχεία:

```bash
(cd data/raw && sha256sum -c wisdm-dataset.zip.sha256)
unzip -n data/raw/wisdm-dataset.zip -d /tmp/har-wisdm-download
unzip -n /tmp/har-wisdm-download/wisdm-dataset.zip -d data/raw
```

Τα δεδομένα του ρολογιού αναμένονται στις διαδρομές `data/raw/wisdm-dataset/raw/watch/accel/*.txt` και `.../watch/gyro/*.txt`. Για τα πειράματα τηλεφώνου χρησιμοποιούνται οι αντίστοιχοι φάκελοι `phone/`.

Αν ο έλεγχος SHA-256 αποτύχει, χρειάζεται έλεγχος του αρχείου που λήφθηκε πριν χρησιμοποιηθεί. Η ασυμφωνία μπορεί να οφείλεται και σε διαφορετική έκδοση του συνόλου δεδομένων· δεν διορθώνεται με απλή αντικατάσταση της αναμενόμενης τιμής.

## 4. Εκτέλεση του κύριου τοπικού πειράματος

Η επιλογή `--config` προηγείται της εντολής `run`:

```bash
python -m har_spark.cli --config configs/watch_fused_10s.yaml run
```

Το πρόγραμμα διαβάζει τις μετρήσεις των δύο αισθητήρων του ρολογιού και υπολογίζει χαρακτηριστικά για χρονικά παράθυρα 10 δευτερολέπτων. Χωρίζει τα δεδομένα ανά άτομο, εκπαιδεύει Λογιστική Παλινδρόμηση και Random Forest και αποθηκεύει τα αποτελέσματα σε νέο φάκελο μέσα στο `results/`, με όνομα που περιλαμβάνει την ημερομηνία και την ώρα εκτέλεσης.

Οι ρυθμίσεις `local[6]` και `4g` στο YAML ορίζουν τους πόρους της τοπικής εκτέλεσης. Σε υπολογιστή με λιγότερους διαθέσιμους πόρους χρειάζονται προσαρμογή, η οποία επηρεάζει και τους χρόνους εκτέλεσης.

Η προεπεξεργασία και η εκπαίδευση μπορούν επίσης να γίνουν χωριστά. Έτσι, τα χαρακτηριστικά υπολογίζονται μία φορά και χρησιμοποιούνται ξανά στην εκπαίδευση:

```bash
python -m har_spark.cli --config configs/watch_fused_10s.yaml prepare
python -m har_spark.cli --config configs/watch_fused_10s.yaml train
```

Η `prepare` αποθηκεύει τα χαρακτηριστικά σε αρχεία Parquet. Η διαδρομή εξόδου πρέπει να είναι νέα, ώστε να μην αντικατασταθούν προηγούμενα αποτελέσματα.

| Αρχείο ρυθμίσεων | Φάκελος αποτελεσμάτων | Πείραμα |
|---|---|---|
| `configs/local.yaml` | `20260827T053553Z` | Επιταχυνσιόμετρο τηλεφώνου, παράθυρα 5 s |
| `configs/fused.yaml` | `20260827T054008Z` | Επιταχυνσιόμετρο και γυροσκόπιο τηλεφώνου, παράθυρα 5 s |
| `configs/fused_10s.yaml` | `20260827T054229Z` | Επιταχυνσιόμετρο και γυροσκόπιο τηλεφώνου, παράθυρα 10 s |
| `configs/watch_fused_10s.yaml` | `20260827T054435Z` | Επιταχυνσιόμετρο και γυροσκόπιο ρολογιού, παράθυρα 10 s |

Στο κύριο τοπικό πείραμα, το Random Forest πέτυχε ορθότητα (accuracy) **62.14%** και macro-F1 **61.90%** σε 2,488 παράθυρα του συνόλου δοκιμής. Για την εκπαίδευση χρησιμοποιήθηκαν δεδομένα 35 ατόμων, για την επικύρωση 8 και για τη δοκιμή άλλων 8. Τα δεδομένα κάθε ατόμου ανήκουν σε ένα μόνο σύνολο.

Οι υπερπαράμετροι ήταν σταθερές· δεν έγινε αυτοματοποιημένη αναζήτηση με βάση το σύνολο επικύρωσης. Σε νέα εκτέλεση, τα αποτελέσματα και οι χρόνοι μπορεί να διαφέρουν λόγω του περιβάλλοντος Spark, της κατανομής των δεδομένων και του υλικού.

## 5. Δημιουργία γραφημάτων από τα αποτελέσματα

Τα γραφήματα μπορούν να δημιουργηθούν ξανά χωρίς νέα εκπαίδευση. Η έξοδος γράφεται σε νέο φάκελο:

```bash
python scripts/generate_plots.py \
  --experiment 'Phone accel 5s=results/20260827T053553Z' \
  --experiment 'Phone fused 5s=results/20260827T054008Z' \
  --experiment 'Phone fused 10s=results/20260827T054229Z' \
  --experiment 'Watch fused 10s=results/20260827T054435Z' \
  --best results/20260827T054435Z --output /tmp/har-new-charts

```

Τα τελικά έγγραφα της εργασίας αναφέρονται στο κεντρικό README. Τα επεξεργάσιμα αρχεία και τα προγράμματα παραγωγής τους δεν περιλαμβάνονται στο αποθετήριο.

## 6. Εκτέλεση στο Google Cloud

Τα αρχεία `cloud/evidence/*_metrics.json` περιέχουν τα αποτελέσματα αξιολόγησης των μοντέλων στο νέφος. Το `cloud/run_summary.json` συνοψίζει την εκτέλεση και το `cloud/deployment.md` περιγράφει την εγκατάσταση που χρησιμοποιήθηκε. Πρόκειται για στοιχεία του πειράματος της 27-08-2026, όχι για έλεγχο της σημερινής κατάστασης του λογαριασμού. Δεν περιλαμβάνονται η αρχική πλήρης απόκριση του API ή αναλυτικά στοιχεία χρέωσης.

Στο νέφος, το Random Forest πέτυχε ορθότητα **61.54%** και macro-F1 **61.09%**. Η συνολική εκτέλεση διήρκεσε **44m 47s**, με χρήση **13.38 DCU-h**.

Οι οδηγίες για νέα εκτέλεση δίνονται στο `cloud/README.md`. Απαιτούνται λογαριασμός Google, έργο με ενεργοποιημένη χρέωση και τα κατάλληλα δικαιώματα. Πριν από την εκτέλεση χρειάζεται έλεγχος της διαθεσιμότητας της υπηρεσίας, των τιμών και των ειδοποιήσεων προϋπολογισμού.

Το αρχείο με το πακέτο Python δημιουργείται τοπικά ως εξής, εφόσον δεν υπάρχει ήδη αρχείο στον ίδιο προορισμό:

```bash
(cd src && zip -r /tmp/har_spark_cloud_submission.zip har_spark -x '*/__pycache__/*' '*.pyc')
```

Το αρχείο ZIP πρέπει να περιέχει τον φάκελο `har_spark/` στη ρίζα του. Ακολουθούν η μεταφόρτωσή του, η ρύθμιση των δικαιωμάτων και η υποβολή της εργασίας στο Google Cloud.
