# Ρυθμίσεις πειραμάτων

Τα αρχεία YAML ορίζουν τις ρυθμίσεις της τοπικής εκτέλεσης. Το `cli.py` επιλέγει το αρχείο ρυθμίσεων, το `config.py` το διαβάζει και το `pipeline.py` χρησιμοποιεί τις τιμές του για να οργανώσει την επεξεργασία και την εκπαίδευση στο Spark.

| Αρχείο | Πείραμα | Χρήση |
|---|---|---|
| [local.yaml](local.yaml) | Επιταχυνσιόμετρο τηλεφώνου, παράθυρα 5 δευτερολέπτων | Προεπιλογή όταν δεν δίνεται `--config` |
| [fused.yaml](fused.yaml) | Επιταχυνσιόμετρο και γυροσκόπιο τηλεφώνου, παράθυρα 5 δευτερολέπτων | Επιλογή με `--config configs/fused.yaml` |
| [fused_10s.yaml](fused_10s.yaml) | Οι δύο αισθητήρες τηλεφώνου, παράθυρα 10 δευτερολέπτων | Επιλογή με `--config configs/fused_10s.yaml` |
| [watch_fused_10s.yaml](watch_fused_10s.yaml) | Οι δύο αισθητήρες ρολογιού, παράθυρα 10 δευτερολέπτων | Κύριο τοπικό πείραμα |
| [smoke.yaml](smoke.yaml) | Ένα αρχείο εισόδου και μικρά μοντέλα | Σύντομος έλεγχος λειτουργίας με `--config configs/smoke.yaml`· δεν προορίζεται για αξιολόγηση της επίδοσης και μπορεί να μην περιέχει δεδομένα αρκετών ατόμων για τον διαχωρισμό σε τρία σύνολα |

Μετά την [εγκατάσταση](../README.md), το κύριο πείραμα εκτελείται από τον φάκελο `supporting/`:

```bash
python -m har_spark.cli --config configs/watch_fused_10s.yaml run
```

Η `run` εκτελεί την προεπεξεργασία και την εκπαίδευση και δημιουργεί νέο φάκελο αποτελεσμάτων. Εναλλακτικά, η `prepare` υπολογίζει και αποθηκεύει τα χαρακτηριστικά, ενώ η `train` εκπαιδεύει τα μοντέλα χρησιμοποιώντας τα χαρακτηριστικά που έχουν ήδη υπολογιστεί.

Για την εκτέλεση στο Google Cloud, το [cloud_pipeline.py](../cloud/cloud_pipeline.py) δέχεται ορίσματα γραμμής εντολών αντί για αυτά τα αρχεία YAML. Η διαδικασία περιγράφεται στις [οδηγίες εκτέλεσης στο νέφος](../cloud/README.md).
